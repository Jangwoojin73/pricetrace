# [PRD] 네이버 쇼핑 가격비교 경량 반응형 웹앱 (PriceTrace WebApp)

- **버전**: 1.0.0
- **레벨**: Starter / Fast Track
- **작성일자**: 2026-09-03
- **상태**: 승인 및 구현 진행

---

## 1. 프로젝트 개요

'네이버 쇼핑 가격 비교 가이드' 로직을 바탕으로, 네이버 쇼핑, 쿠팡, 지마켓 등 국내 주요 이커머스 쇼핑몰의 전형적이고 친숙한 가격비교 UX를 웹 화면으로 제공합니다.  
사용자는 특정 생필품(예: 농심 신라면 봉지 20개입)의 실시간 최저가, 1봉당 환산 단가, 쇼핑몰별 가격 비교 순위, 목표 가격 대비 절감액 및 특가 발생 여부를 웹 브라우저에서 한눈에 직관적으로 확인할 수 있습니다.

---

## 2. 사용자 페르소나 및 핵심 문제

- **페르소나**: 생필품(라면, 생수 등)을 주기적으로 온라인으로 박스 구매하며, 최저가와 혜택을 꼼꼼히 따지는 스마트 컨슈머.
- **핵심 문제**:
  1. 포털 검색 결과에 광고(Ad)나 다른 규격(40개, 컵라면, 파생 라면)이 뒤섞여 있어 진짜 최저가를 찾기 번거로움.
  2. 총액만 보면 1봉당 얼마인지 즉시 계산하기 어려움.
  3. 지금 가격이 평소 대비 싼 편인지(목표가 이하인지) 판단하기 어려움.

---

## 3. 핵심 요구사항 (Functional Requirements)

### FR-1: 실시간 최저가 카탈로그 요약 (Hero Section)
- 타깃 상품(기본: 농심 신라면 봉지 20개입)의 대표 이미지, 상품명, 평점, 총 리뷰 수 표시
- 실시간 1위 최저가 금액 및 1봉당 환산 단가(총액 ÷ 20) 자동 계산 표시
- 목표가(기본 15,000원) 대비 절감액 및 특가 상태 뱃지(`🚨 [특가 발생] 목표 가격 이하!` / `ℹ️ [유지] 아직 목표 가격보다 비쌉니다`) 표시
- 최저가 쇼핑몰 바로가기 아웃링크 제공

### FR-2: 판매처별 가격비교 매트릭스 (Price Comparison Matrix)
- 네이버 쇼핑 카탈로그 순위 리스트 (1위, 2위, 3위 메달 표시)
- 판매처명(예: 네이버 가격비교, 신성마켓몰 등), 실결제 가격, 리뷰 수, 평점
- 광고(AD) 상품 및 파생 라면 자동 배제 상태임을 알려주는 '클린 필터링' 안심 뱃지 노출

### FR-3: 가격 변동 추이 및 구매 적기 판별 (Price Trend & Indicator)
- 최근 30일 모의/실제 최저가 변동 라인 차트 (Chart.js 연동)
- "현재 가격 진단 (Buy Indicator)": 목표가 대비 현재 가격의 할인 수준을 시각화

### FR-4: 스마트 검색 및 인터랙션
- 검색어 입력 및 인기 키워드 원클릭 태그 제공
- 데이터 '새로고침' 버튼 클릭 시 네이버 쇼핑 실시간 크롤러 재호출 및 스켈레톤 UI 표시
- 모바일/태블릿/데스크톱 완벽 대응 반응형 레이아웃

---

## 4. 비기능적 요구사항 (Non-Functional Requirements)

1. **설치 편의성**: 복잡한 외부 종속성 없이 Python 내장 서버로 단일 실행 가능
2. **응답 속도**: 초기 로드 0.5초 이내, 실시간 크롤링 요청 시 로딩 스피너 및 에러 폴백 보장
3. **디자인 품질**: `frontend-design` 스킬을 준수하여 상용 이커머스 수준의 세련된 시각 요소 적용 (Pretendard 폰트, 일관된 색상 테마, 마이크로 인터랙션)
